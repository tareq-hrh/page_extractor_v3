Target Tabs
Current tab extracts only the active page. All tabs extracts every supported tab in this browser window.
Content Scope
Article uses Readability for the main article. Full page keeps more of the visible page structure.
Output Format
Text is easiest to read and search. HTML keeps cleaned page structure and links.
File Name Settings
Browsers do not expose the configured download folder here. Enter only a relative folder path, such as products/20_09_2026. The file is saved inside the browser's own download location.
Notes / Header Text
Notes are written into the exported file header before the page content.
