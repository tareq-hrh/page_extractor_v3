# Extraction Quality Fixtures

These fixtures document the expected shape of Phase 3 text extraction.

- `extraction-quality-sample.html` contains headings, links, hidden content, nested lists, tables, and a code block.
- `extraction-quality-expected-body.txt` shows the expected body text after extraction formatting, before the export metadata header is added.

For link output comparison, serve or open the sample from a stable base URL such as `https://example.test/fixtures/extraction-quality-sample.html`; relative links are resolved against the page URL during extraction.
